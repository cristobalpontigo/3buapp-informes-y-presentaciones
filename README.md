## Cómo editar o comentar

El equipo tiene permiso de escritura en este repositorio.

- Para corregir la presentación, editen `index.html` en GitHub o clonen el repositorio y suban los cambios a `main`.
- Para observaciones, dudas o aportes sin tocar el archivo, abran un issue o respondan en uno ya abierto. Los issues quedan habilitados para eso.
